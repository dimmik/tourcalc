# Сервер на Cloudflare Workers — прототип

Цель — уйти с дроплета DigitalOcean. Вопрос прототипа: собирается ли наш код под Workers и
укладывается ли в бесплатные лимиты. Только чтение: `dimmik/tc-strg-test` пишет бета, второй
писатель потерял бы правки.

Ветка `cf/worker-proto` (не `beta/*`: сборку беты не трогает). Адрес:
<https://tc-proto.dimmik-a.workers.dev>.

## Что в нём

`worker/` — крейт на [`workers-rs`](https://github.com/cloudflare/workers-rs) 0.8.7, вне
workspace `rust/`.

- `GET /api/Info/version` — один Worker, без хранилища.
- `GET /api/Tour/:id` — тур из хранилища GitHub. Через Durable Object `Store` (один на всё
  хранилище, как процесс сервера): он держит в памяти список файлов ветки (3 запроса к
  GitHub, перечитывается раз в минуту) и кладёт прочитанные файлы в своё хранилище SQLite по
  git sha — это кэш на диске сервера. Расшифровка — тот же `tc-server/src/github/seal.rs`,
  подключённый `#[path]`, не копия.
- `GET /calc/:id` — тур, балансы и предложение расчёта (`tc_core::calc`) внутри Durable
  Object.
- `GET /calc-here/:id` — то же, но счёт в самом Worker-е (там 10 мс процессора на бесплатном
  тарифе).
- В ответах `X-Tc-*`: сколько запросов к GitHub, из хранилища ли файл, голова ветки.

Секреты (`wrangler secret put`): `GITHUB_TOKEN` (токен репозитория данных), `STORE_KEY`
(`GitHubStoreKey`). Переменные — в `wrangler.toml`.

## Как собрать и выложить

Нужны Node (`wrangler`, версия в `package.json`) и `worker-build` (`cargo install
worker-build --version 0.8.7 --locked`), toolchain — как у сервера (`RUSTUP_TOOLCHAIN=1.98.1`).

```
cd cloudflare/worker
npm install
CLOUDFLARE_ACCOUNT_ID=… CLOUDFLARE_API_TOKEN="$(cat <файл>)" npx wrangler deploy
CLOUDFLARE_ACCOUNT_ID=… CLOUDFLARE_API_TOKEN="$(cat <файл>)" npx wrangler tail tc-proto --format json
```

В логе `wrangler tail` у каждого вызова есть `cpuTime` и `wallTime` (мс), отдельно у Worker-а
и у Durable Object.

Туры из `tc-strg-test`: `uvz4qis` (2 КБ, 3 человека), `73uiupn` (20 КБ, 15 человек, меню).

## Что из этого следует

- **Код переносится.** `tc-core` и шифрование хранилища собрались под Workers без правок.
  Не переносятся только среда (`tokio`, `reqwest`, `axum`, диск) — это и есть работа.
- **Тяжёлое — в Durable Object**, а Worker только передаёт запрос: тогда лимит 10 мс не
  встречается. Объект и так нужен: один писатель с памятью и коммитом по таймеру (alarm).
- **Не проверено:** туры крупнее 20 КБ (самые большие в проде), запись — коммит по alarm,
  push-уведомления (шифрование на подписчика), текстовые страницы `/t`, отдача клиента
  (статика бесплатна и вне лимита запросов), сколько живёт прогретый экземпляр.
